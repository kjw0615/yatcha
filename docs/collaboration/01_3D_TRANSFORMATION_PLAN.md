# 3D Yacht Dice (야추 3D) 리마스터 기획 및 멀티 에이전트 협업 가이드

## 1. 개요 및 비전
기존 2D 평면 기반의 Godot 요트 다이스(Yacht Club) 게임을 **3D 물리 기반 인터랙티브 주사위 게임**으로 전면 탈바꿈합니다.
- **게임 규칙 유지**: 기존 12칸 족보(Aces ~ Yacht), 점수 계산 로직(`scripts/rules.gd`), 최대 323점 체계는 100% 보존.
- **새로운 3D 비주얼 & 작동 방식**:
  1. 3D 주사위 컵(Dice Cup) 흔들기 및 굴리기(물리 시뮬레이션: RigidBody3D / Physics Engine).
  2. 트레이 / 테이블 위의 실시간 3D 주사위 오브젝트(주사위 눈에 따른 윗면 판정 알고리즘).
  3. 마우스/터치 드래그 또는 키보드로 주사위를 픽업하여 킵(Keep) 구역과 롤(Roll) 구역으로 물리적 이동.
  4. 세련된 3D 테이블탑 환경, 3D 다이스 트레이 및 모던 글래스모피즘(Glassmorphism) 3D UI/HUD.

  2. **점수판 HUD 및 UI 레이아웃 기획**: 3D 공간과 조화되는 반응형 점수판 UI(스위치 스타일 + 모던 글래스 테마).
