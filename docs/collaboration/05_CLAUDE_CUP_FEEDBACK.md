# 05. 컵 흔들기 HUD 연출 및 시각 검수 보고

- 작성: Claude Code · 2026-11-19
- 변경 파일: `scripts/main_3d.gd` (HUD만). `board_3d.gd`, `die_3d.gd`, 씬 파일은 수정하지 않음.

## 1. 변경 내용 (흔들기 게이지 · 타이밍 가이드)

`board_3d`가 매 프레임 내보내는 `cup_state_changed(true, power)`의 `power`(0.2~1.8)를 HUD에 시각화했다.

| 파워 | 구간 | 색 | 문구 |
|---|---|---|---|
| < 0.5 | 약함 | 회청 `#6f8aa0` | 조금 더 흔드세요 |
| 0.5 ~ 1.3 | 적정 | 민트 `#76e5c0` | 언제든 던질 수 있습니다 |
| 1.3 ~ 1.78 | 강함 | 주황 `#f2b56b` | 멀리 굴러갑니다 |
| ≥ 1.78 | MAX | 주홍 `#ff8a5c` | 지금 떼어서 던지세요! |

- 3D 뷰 아래, 굴리기 버튼 위에 `ProgressBar`(높이 16)와 한 줄 문구를 추가했다.
- 구간이 바뀔 때만 스타일을 갱신해 매 프레임 `StyleBox`를 만들지 않는다.
- 던지거나 흔들기를 끝내면 게이지가 0으로 돌아가고 "Space를 길게 눌러 통을 흔드세요"가 표시된다.
- 임계값(0.5)은 `board_3d.execute_throw`의 `clamp(power, 0.5, 2.0)` 하한과 맞췄다. 0.5 미만은 실제로는 0.5로 던져지므로 "약함"은 "아직 힘이 덜 쌓였다"는 안내일 뿐 결과가 더 약해지는 것은 아니다.
- 색만으로 구분하지 않도록 구간마다 문구도 다르게 했다.

## 2. 시각 검수

주사위 눈 텍스처(`assets/textures/die_face_1~6.png`)는 5번·6번을 직접 확인했다.

| 항목 | 판정 | 비고 |
|---|---|---|
| 눈 대비 | 양호 | 짙은 남색 점(`#1a2a3a` 계열) on 밝은 면. 큰 지름 |
| 면 구성 | 양호 | 6개 quad가 0.501 오프셋으로 본체 위에 올라가 있어 z-fighting 위험 낮음. 쌍 합 7 규칙은 `die_3d.gd`와 일치 |
| 트레이 | 양호 | 짙은 청록 펠트 `(0.08,0.25,0.22)` 위에서 밝은 주사위가 확실히 분리됨 |
| 컵 | 주의 | 갈색 반투명(alpha 0.85)이라 안의 주사위가 비쳐 보이는 것은 의도에 맞음. 다만 벽(짙은 갈색)과 색이 가까워 컵이 벽 근처에서 묻힐 수 있음 |
| 글래스 테마 | 미적용 | 기획서 §3.3의 반투명 블러 패널은 아직 반영되지 않음(현행은 기존 `StyleBoxFlat`) |

## 3. 확인하지 못한 것 / 후속 제안

- **실제 화면 검수는 하지 못했다.** 헤드리스 환경이라 스크린샷을 찍지 않았고, 게이지 색·위치와 주사위 면 방향(회전된 quad에서 눈이 뒤집혀 보이지 않는지)은 눈으로 확인하지 않았다. Antigravity가 `play.cmd`로 실행해 한 번 봐 주면 좋다.
- **보드 이탈 방지**(사용자 요청 1)는 이번 담당이 아니어서 건드리지 않았다. 참고로 벽은 높이 5, 천장 충돌체가 있어 `board_3d.execute_throw`에서 컵 위치(`y≈3.8`)로 시작하는 주사위가 천장·벽 사이에서 끼지 않는지 확인이 필요하다.
- 컵 색을 벽과 구분되는 밝은 톤(예: 따뜻한 베이지 + 짙은 테두리)으로 바꾸면 가독성이 좋아질 것이다. `board_3d.gd`의 `cup_mat.albedo_color`를 바꾸는 한 줄 작업이라 담당자에게 맡긴다.
- 문구에 쓰인 "던지기 가이드"는 텍스트·색 기반이다. 컵 테두리에 월드 공간 링 게이지(기획서 §2.2)는 `board_3d` 쪽 작업이라 포함하지 않았다.
