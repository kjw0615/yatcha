# 3D Yacht Dice 자체 QA 계획 및 전담 매트릭스

## 1. 개요
3D 리마스터된 게임의 완성도와 사용자 경험(UX)을 대폭 향상시키기 위해 **자체 종합 QA (품질 보증)**를 진행합니다.
- **QA 총괄 리드**: **Claude Code (`t3j`)**
  - 근거: `SKILLS_OVERVIEW.md`의 파이프라인에서 Claude Code는 '기획 수립 및 최종 시각/UX 검수' 전담.
  - 임무: 사용성(UX), 3D 카메라 연출 및 HUD 가독성, 예외 상황(사용자 조작 실수, 연속 입력 등) 시나리오 검증 및 이슈 리포트 작성.
- **엔지니어링 & 물리 QA 지원**: **OpenAI Codex (`t3k`)**
  - 임무: 물리 엔진 극한 상황(주사위 겹침, 고속 회전 시 벽 뚫림 터널링, 슬립 판정 지연 등) 시뮬레이션 및 자동화 테스트 케이스 보강.
- **QA 조율 & 핫픽스 총괄**: **Antigravity (팀장)**
  - 임무: 보고된 버그 우선순위 지정, PR 승인/머지 및 최종 빌드 검증.

## 2. QA 중점 검증 영역 (QA Focus Areas)

### 1) 3D 카메라 & 시각적 피드백 (Claude 담당)
- [ ] 주사위를 굴리고 멈출 때 카메라가 주사위들의 중심을 자연스럽게 잡아주는지
- [ ] 3D 뷰포트와 우측 점수판 간의 레이아웃 조화 및 글래스모피즘 HUD 가독성
- [ ] 컵을 흔들 때 게이지와 주사위 텍스처(1~6 핍)의 시인성

### 2) 조작성 & 게임 루프 예외 처리 (Claude 담당)
- [ ] Space 키와 마우스 버튼을 빠르게 연타했을 때의 비정상 동작(중복 롤링, 턴 꼬임) 방지
- [ ] 3회 굴림 소진 후 주사위 토글 및 족보 선택의 직관성
- [ ] 게임 종료(12라운드 종료) 시 승리 판정 및 새 게임 초기화의 무결성

### 3) 3D 물리 & 터널링 극한 테스트 (Codex 담당)
- [ ] 컵 파워 MAX(최대 충격량)로 던졌을 때 주사위가 5.0m 벽이나 천장을 뚫고 나가는 현상(터널링) 유무
- [ ] 주사위 두 개가 서로 위에 포개져 비스듬히 멈추었을 때 윗면 판정 알고리즘의 신뢰성
- [ ] 킵(Keep) 이동 중 주사위가 다른 주사위와 충돌하여 튕겨나가지 않는지(Kinematic 보간 안전성)

## 4.3 점검 결과 (이상 없음)

- Space 연타: `echo` 무시, `busy` 동안 시작 차단, 던지는 0.2초 구간도 `busy`가 선행되어 이중 던지기 없음.
- 3회 소진 후: 굴리기 버튼 비활성, 족보 선택·확정은 가능. 5개 모두 킵이면 굴리기 비활성.
- 턴 종료 시 킵 해제 및 `rolls` 초기화, 12라운드 종료 판정은 `test_game.gd`로 통과.
- 주사위 눈 텍스처: 밝은 면 + 짙은 남색 큰 점, 트레이 펠트와 분리됨(5·6번 직접 확인). 면 방향은 `die_3d`의 1/6, 2/5, 3/4 규칙과 일치.
- 파워 게이지: 구간별 색 + 문구, 임계값은 `execute_throw`의 하한(0.5)과 일치.
