# YACHT CLUB · 요트 다이스

Godot 4.6 / GDScript로 만든 로컬 2인용 2D 프로토타입입니다.
외부 이미지, 플러그인, 유료 에셋 없이 동작합니다.

## 실행

- **play.cmd** 더블 클릭: 게임 실행. `tools/godot`의 공식 Godot 4.6 실행 파일을 사용합니다.
- **edit.cmd** 더블 클릭: Godot 편집기에서 프로젝트 열기. F6 대신 **F5**로 전체 게임 실행.
- 별도의 Godot 4.6 이상을 쓸 경우 `project.godot`를 가져오고 F5를 누릅니다.
- tools 폴더는 실행 편의를 위한 로컬 엔진이며 프로젝트 소스에는 포함하지 않습니다.

## 플레이

한 컴퓨터에서 두 사람이 번갈아 조작합니다. 주사위 굴리기 → 주사위 클릭으로 보관 → 필요하면 재굴림 → 점수표의 자기 칸 선택 → 기록 확정 순서입니다. 첫 굴림 이후 언제든 기록할 수 있고, 턴당 최대 세 번 굴립니다. 기록할 수 없는 족보도 0점으로 소진할 수 있습니다. 한 번 기록한 칸은 바꿀 수 없습니다. 두 사람이 각각 12칸을 채우면 승패 또는 무승부를 표시합니다.

## 채택한 규칙

| 족보 | 조건과 점수 |
|---|---|
| 에이스~헥사 | 각각 1~6 눈의 합 |
| 숫자 보너스 | 위 6개 합계 63 이상이면 35점 추가 |
| 초이스 | 주사위 전체 합 |
| 포카드 | 같은 눈 4개 이상이면 주사위 전체 합 |
| 풀하우스 | 정확히 3개+2개면 주사위 전체 합. 요트는 인정하지 않음 |
| 스몰 스트레이트 | 연속된 서로 다른 눈 4개 이상이면 15점 |
| 라지 스트레이트 | 연속된 서로 다른 눈 5개면 30점 |
| 요트 | 같은 눈 5개면 50점 |

원형 Yacht와 Yahtzee, 스위치 게임은 족보 수와 점수에 차이가 있습니다. 이번 버전은 스위치의 12칸 방식에 가까운 변형이며, 풀하우스의 요트 인정 여부는 명시적으로 불인정으로 정했습니다. 추가 요트 보너스 및 조커 규칙은 없습니다. 최대 점수는 323점입니다.

## 구조와 검증

- `main.tscn`: 시작 장면.
- `scripts/main.gd`: 화면, 굴리기, 보관, 턴, 점수 확정, 승패.
- `scripts/rules.gd`: 화면에서 분리된 순수 점수 계산.
- `scripts/die.gd`: 벡터로 그리는 주사위.
- `tests/test_game.gd`: 족보 경계값, 보관, 3회 제한, 중복 기록 방지, 24턴 종료 및 재시작 검증.

검증 명령: `Godot_v4.6-stable_win64_console.exe --headless --path . --script tests/test_game.gd`

## 현재 범위와 다음 확장

프로토타입은 로컬 2인 대전, 한국어 화면, 굴림 애니메이션, 예상 점수, 기록 확인, 최근 기록, 규칙 안내, 재시작을 제공합니다. AI 상대, 네트워크 대전, 저장/복원, 사운드, 3D 물리 주사위, 플랫폼 배포 빌드는 포함하지 않습니다. 우선 실제 플레이로 점수표 가독성과 턴 흐름을 확인한 뒤 AI 또는 3D 주사위를 추가할 수 있습니다. 기존 제품의 그래픽이나 상표 에셋은 사용하지 않았습니다.
